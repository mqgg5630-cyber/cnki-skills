# 📚 CNKI Scholar Assistant — 知网学术助手浏览器插件

> 打开知网即可使用：文献搜索 · 批量PDF下载 · 引用导出 · 综述生成 · 机构账号识别

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🔍 **智能检索** | 主题/题名/作者/摘要/关键词多字段检索，支持来源类别（CSSCI/SCI/北大核心等）和年份范围过滤 |
| 📄 **PDF一键下载** | 在搜索结果页直接点击下载，无需进入详情页；支持批量多选下载 |
| ⭐ **文献收藏** | 将感兴趣的文献保存到本地文库，永久保存，支持离线查看 |
| 📋 **引用导出** | 一键生成 GB/T 7714 格式引用，支持批量导出，可直接粘贴到论文 |
| ✍️ **综述生成** | 基于检索结果自动生成学术综述；支持接入 OpenAI/Claude/DeepSeek/通义千问 API 生成高质量综述 |
| 🏫 **机构账号识别** | 自动识别知网IP认证机构，显示机构名称和权限状态 |
| 🔗 **Zotero集成** | 支持推送到本地 Zotero（需要 Zotero 桌面端运行） |
| 🛠️ **悬浮工具栏** | 在知网所有页面注入悬浮操作栏，支持拖拽，批量操作触手可及 |

## 📦 安装方法（开发者模式）

### 1. 下载插件

```bash
# 克隆仓库
git clone https://github.com/mqgg5630-cyber/cnki-skills.git
cd cnki-skills/browser-extension
```

或者直接下载 `browser-extension` 文件夹。

### 2. 在 Chrome 中加载

1. 打开 Chrome，地址栏输入：`chrome://extensions/`
2. 右上角开启「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」
4. 选择 `browser-extension` 文件夹
5. ✅ 插件已安装！

### 3. 使用插件

1. 打开 [知网](https://www.cnki.net)
2. 点击浏览器右上角的 📚 图标，打开弹出面板
3. 或使用页面右下角的悬浮工具栏直接操作

## 🖥️ 界面说明

### 弹出面板（Popup）

点击浏览器工具栏图标打开，包含 4 个标签页：

#### 🔍 检索标签
- 输入关键词，选择字段和来源类别
- 结果列表支持多选、批量下载、批量导出引用
- 每条结果可单独收藏、下载PDF、查看详情

#### 📖 文库标签
- 查看所有已收藏文献
- 支持批量导出引用、删除单条记录

#### ✍️ 综述标签
- 输入综述主题，配置参数
- **无需API Key**：自动整理文献信息生成结构化综述
- **接入AI**：选择 OpenAI/Claude/DeepSeek/通义千问，输入 API Key，生成专业学术综述
- 支持下载为 RTF（Word可打开）或打印为 PDF

#### 👤 账号标签
- 实时显示知网登录状态和机构认证信息
- 配置下载格式、自动重命名
- 配置 Zotero 端口并测试连接
- 统计下载量、收藏量、综述数量

### 悬浮工具栏

在知网页面右下角自动显示，包含：

| 按钮 | 功能 |
|------|------|
| 🔍 | 打开搜索面板 |
| ⭐ | 批量收藏已选文献 |
| 📋 | 导出所选文献引用 |
| 📄 | 批量下载所选PDF |
| ✍️ | 在页面内生成综述 |

支持拖拽到任意位置，点击「─」最小化。

### 搜索结果页增强

- 每行文献悬停时显示快捷按钮：⭐收藏 / 📄PDF / 📋引用
- 顶部增加「全选当页」「批量PDF」「导出引用」「生成综述」工具栏
- 已选条目高亮显示

## 🤖 AI 综述接入

支持以下 AI 模型（需要相应 API Key）：

| 模型 | API Key 获取 |
|------|-------------|
| OpenAI GPT-4 | [platform.openai.com](https://platform.openai.com) |
| Anthropic Claude | [console.anthropic.com](https://console.anthropic.com) |
| DeepSeek | [platform.deepseek.com](https://platform.deepseek.com) |
| 通义千问 | [dashscope.aliyun.com](https://dashscope.aliyun.com) |

> API Key 仅存储在本地 Chrome Storage，不上传任何服务器。

无 API Key 时，插件仍可自动整理文献摘要，生成结构化综述框架。

## 🏫 机构账号说明

插件支持以下认证方式，**无需额外配置**：

1. **IP认证**：通过机构校园网或 VPN 访问知网，插件自动识别机构名称
2. **账号登录**：在知网网页登录账号，插件自动读取登录状态
3. **手动标注**：在账号设置页面手动输入机构名称（仅用于界面显示）

---

## ⚠️ 注意事项

- **下载功能**需要先登录知网账号（或通过机构IP）
- 如遇**滑块验证码**，请手动在知网页面完成验证后重试
- 知网对批量操作有频率限制，批量下载时插件自动添加延迟
- 本插件仅供个人学术研究使用，请遵守知网用户协议
